# Domain docs

This is a single-context repository.

Before exploring or changing behavior, read the relevant sections of:

- `CONTEXT.md` for canonical domain terms and invariants;
- `docs/adr/` for architectural decisions that touch the requested area;
- `PLAN.md` for implementation scope, milestones, and release gates.

Use the vocabulary defined in `CONTEXT.md` in issue titles, specifications, code comments, and tests. If a change conflicts with an ADR, identify the conflict explicitly and propose reopening the ADR rather than silently overriding it.

# Keep permanent Safe Delete in Advanced Mode

Simple Mode will offer recoverable Trash deletion where the operating system or destination supports it. Permanent Removal will be available only in Advanced Mode, clearly labeled as irreversible, and require fresh confirmation for every run.

If Trash is unavailable, SyncPlus will not silently substitute Permanent Removal. The run will stop or require the user to change the deletion method explicitly. This preserves a recovery path for ordinary users while retaining a deliberate space-reclamation option for experienced users.

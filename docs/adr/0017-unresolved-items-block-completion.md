# Keep unresolved items visible and block completion

Skipped, unavailable, locked, changing, failed, or cancelled items are Unresolved Items. They remain in the run report and prevent the final **Complete** action. This ensures that a user cannot mistake a partial transfer pass for a fully reviewed and cleared run.

An item may become resolved when the user successfully applies a reviewed decision, or when the user explicitly removes it from the run's scope and acknowledges that it will remain outside this run. Scope removal is recorded as a decision; it is not treated as a successful transfer or source cleanup.
